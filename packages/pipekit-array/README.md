# pipekit-array

Duck-typed array operators on top of `pipekit`, implemented against the [Python Array API standard](https://data-apis.org/array-api/). Multi-backend: numpy, JAX, CuPy, PyTorch.

See [Report 3 — Sister libraries](https://github.com/jejjohnson/research_journal_v2/blob/main/notes/geotoolz/master_plan/toolz_3_pipekit_array.md).
