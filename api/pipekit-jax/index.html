    pipekit-jax¶

    JAX / Equinox carrier integration for pipekit. Ships JaxModelOp (the public counterpart of the in-package pipekit_train.adapters.equinox.EquinoxModelOp, adding byte-identical weight round-trip through pipekit_experiment.ModelRegistry via the registry's weights blob), DiffraxForwardModel (a pipekit_cycle.ForwardModel behind the [diffrax] extra), and the adjoint interpreters to_diffrax_adjoint / truncated_scan.

    Pytree containers¶

    Importing pipekit_jax registers pipekit.Sequential, pipekit.Graph and JaxModelOp as JAX pytrees, so jax.grad / eqx.filter_grad / jax.vmap see through a pipeline to the leaves of the operators it holds.

    pipekit_jax.pytree ¶

    Register pipekit's composition containers as JAX pytrees.

    Importing pipekit_jax registers pipekit.Sequential, pipekit.Graph and pipekit_jax.JaxModelOp with jax.tree_util, so JAX transformations see through a pipeline to the leaves of the operators it holds:

    • Sequential — children are its operators, in order.
    • Graph — children are the node operators in topological order; the topology (inputs, node wiring, outputs) is static aux data that holds no operators or parameters.
    • JaxModelOp — the child is its wrapped eqx.Module.

    Without the registration a container is a single opaque leaf, and a learnable coefficient on an operator inside it is a constant to jax.grad / eqx.filter_grad. pipekit core stays JAX-free: the registration is an import side effect of this package, like enabling a jax.config flag.

    What the leaves are depends on the operators. An operator that is itself a pytree (an eqx.Module subclass, or JaxModelOp via its module) contributes its own leaves. A plain pipekit.Operator is one opaque leaf — fine under eqx.filter_jit / eqx.filter_grad (non-array leaves are static there), but not as a direct argument to jax.jit.

    Caveats:

    • Registration is by exact type. Subclasses of Sequential / Graph are not registered automatically.
    • Operator sharing is not preserved. An operator instance used by two graph nodes flattens to two children; after an unflatten with new leaves they are two independent objects. (Equinox modules behave the same way.)
    • Other containers (Fanout, Branch, Switch, Cache, Try, the parallel maps) are not registered yet.
    Example

    import equinox as eqx, jax, jax.numpy as jnp import pipekit_jax # registers the containers from pipekit import Operator, Sequential class Scale(Operator, eqx.Module): ... factor: jax.Array ... def _apply(self, x): ... return self.factor * x pipe = Sequential([Scale(jnp.asarray(2.0)), Scale(jnp.asarray(3.0))]) len(jax.tree.leaves(pipe)) 2

    JaxOperator¶

    Base class for operators that are both a pipekit.Operator and an eqx.Module: JSON-safe config, pytree leaves, and the weight-blob round trip. Use check_jax_operator in a library's test suite to assert the contract (eager ≡ jit, batching, visible leaves, a config round trip that keeps learnable fields learnable).

    pipekit_jax.operator ¶

    JaxOperator — a pipekit Operator that is also an eqx.Module.

    Domain libraries (finitevolX, spectraldiffx, somax, …) need operators that are both:

    • pipekit operators — dual-mode __call__ (eager / graph node), | composition, and a JSON state / from_state round trip;
    • Equinox modules — array fields are pytree leaves, so the operator works under jax.jit / jax.grad / jax.vmap, and config-only fields are eqx.field(static=True).

    The two compose because Equinox generates a dataclass __init__ from the fields, and that is exactly the signature pipekit's ConfigMixin reads to build get_config(). JaxOperator makes the combination explicit, coerces array fields to JSON in get_config(), and adds the WeightsMixin byte round trip.

    Writing one::

    class Diffuse(JaxOperator):
    '''u ↦ u + κ ∇²u on a periodic 1-D grid (κ learnable).'''

    dx: float = eqx.field(static=True)        # config, not a leaf
    kappa: jax.Array = eqx.field(converter=jnp.asarray)   # leaf

    def _apply(self, u):
        lap = (jnp.roll(u, -1) - 2 * u + jnp.roll(u, 1)) / self.dx**2
        return u + self.kappa * lap

    Learnable fields: give them converter=jnp.asarray. A JSON reload passes a Python float back into the constructor, and a Python float is not an inexact array — without the converter the reloaded parameter is silently treated as a constant by eqx.filter_grad. pipekit_jax.testing.check_jax_operator catches this.

    Compiling: use eqx.filter_jit(op) (or jax.jit on a function that takes op as an argument). jax.jit(op) hashes the callable, and an eqx.Module with array fields is unhashable.

    class JaxOperator(Operator, WeightsMixin, eqx.Module):
    """Base class for pipekit operators whose fields are Equinox fields.

    Subclasses declare fields as on any ``eqx.Module`` and implement
    ``_apply``. ``Operator`` comes first in the MRO, so pipekit's
    dual-mode ``__call__`` is the one that runs (Equinox defines no
    ``__call__``).

    - **Config**: ``get_config()`` is auto-derived from the generated
      ``__init__`` and coerced to JSON builtins (`jsonable`), so
      ``op.state`` survives ``json.dumps`` and ``Operator.from_state``.
      Real numbers, strings, booleans, (nested) lists / tuples and
      str-keyed dicts of them round-trip, and so do nested operators
      (their ``state`` records, which ``from_state`` rebuilds);
      ``op.state`` raises ``TypeError`` for complex values, and for
      array fields whose converter would not restore their dtype (JSON
      drops dtypes: a ``float16`` field needs a casting converter).
      Operators holding non-array Python objects (callables, modules
      without a JSON form) should set ``forbid_in_yaml = True`` and
      persist through `serialize_weights` / `with_weights`.
    - **Leaves**: inexact-array fields are differentiable; mark
      config-only fields ``eqx.field(static=True)``; give learnable
      fields ``converter=jnp.asarray`` (see the module docstring).
    - **Weights**: `serialize_weights` / `with_weights` /
      `from_registry` persist the operator's own array leaves.
    """

    def get_config(self) -> dict[str, Any]:
        """JSON-builtin constructor config (arrays → scalars / lists)."""
        return {k: jsonable(v) for k, v in super().get_config().items()}

    @property
    def state(self) -> dict[str, Any]:
        """JSON-serialisable state record, validated for a round trip.

        Raises:
            TypeError: if a config value cannot survive ``json.dumps`` →
                ``Operator.from_state`` (complex numbers, dicts) and the
                class is not marked ``forbid_in_yaml``.
        """
        record = super().state
        if type(self).forbid_in_yaml:
            # Not round-trippable by design, but still JSON-encodable so a
            # registry can store the record next to the weight blob.
            record["config"] = {
                k: v if _json_safe(v) else _debug_repr(v)
                for k, v in record["config"].items()
            }
            return record
        if not type(self).forbid_in_yaml:
            bad = [k for k, v in record["config"].items() if not _round_trips(v)]
            if bad:
                raise TypeError(
                    f"{type(self).__name__}: config field(s) {bad} cannot round-trip "
                    "through JSON and Operator.from_state (complex values, and "
                    "dicts keyed exactly {'class', 'config'}, are not supported). "
                    "Store them as real numbers or lists of pairs, or set "
                    "`forbid_in_yaml = True` and persist arrays with "
                    "serialize_weights()."
                )
            lossy = self._dtype_lossy_fields()
            if lossy:
                raise TypeError(
                    f"{type(self).__name__}: array field(s) {lossy} would reload "
                    "with a different dtype: JSON drops dtypes and the field's "
                    "converter does not restore it. Give the field a casting "
                    "converter, e.g. eqx.field(converter=lambda x: "
                    "jnp.asarray(x, jnp.float16)), or set `forbid_in_yaml = True` "
                    "and persist arrays with serialize_weights()."
                )
        return record

    def _dtype_lossy_fields(self) -> list[str]:
        """Array config fields whose JSON round trip changes their dtype.

        Rebuilds each array field the way ``from_state`` does (its JSON
        value passed through the field's converter) and compares dtypes.
        A field without a converter reloads as a Python scalar / list;
        `check_jax_operator` reports that case as a lost learnable leaf.
        """
        lossy = []
        for f in dataclasses.fields(self):
            converter = f.metadata.get("converter")
            if not f.init or converter is None:
                continue
            value = getattr(self, f.name)
            if not eqx.is_array(value):
                continue
            rebuilt = converter(jsonable(value))
            if not eqx.is_array(rebuilt) or rebuilt.dtype != value.dtype:
                lossy.append(f.name)
        return lossy

    def jsonable(value: Any) -> Any:
    """Coerce a config value to JSON builtins.

    Arrays (JAX or NumPy) become a Python scalar (0-d) or nested lists;
    tuples (including named tuples) become plain tuples and lists plain
    lists, converted recursively — JSON drops the subclass anyway; dicts
    are converted recursively; everything else is returned unchanged.
    """
    if isinstance(value, np.ndarray | np.generic) or eqx.is_array(value):
        arr = np.asarray(value)
        return arr.item() if arr.ndim == 0 else arr.tolist()
    if isinstance(value, tuple):
        return tuple(jsonable(v) for v in value)
    if isinstance(value, list):
        return [jsonable(v) for v in value]
    if isinstance(value, dict):
        return {k: jsonable(v) for k, v in value.items()}
    return value

    check_jax_operator(op, *inputs, vmap=True) ¶

    Assert that op behaves as a JAX-native pipekit operator.

    Checks, in order:

    1. op is a pipekit Operator and an eqx.Module.
    2. Eager ≡ jit: op(*inputs) equals eqx.filter_jit of the same call, with op passed as an argument (so its leaves are traced).
    3. Batching (when vmap): stacking every input array along a new leading axis and jax.vmap-ing gives the stacked eager outputs. Non-array inputs (strings, callables, metadata) are held static.
    4. Leaves visible: every inexact-array field of op is a leaf of jax.tree.leaves(op), and eqx.filter_grad of a scalar loss returns a gradient for each of them.
    5. Config round trip (unless forbid_in_yaml): op.state survives json.dumps → Operator.from_state; the rebuilt operator has the same number of inexact-array leaves (a learnable field that came back as a Python float fails here), the same array leaves (shape / dtype), and the same outputs. Static fields may change container type (a tuple reloads as a list). For an operator whose config nests operators ({"class", "config"} payloads), the children are taken from the live operator and the rest is rebuilt from JSON, so local fields are still checked.
    6. No static field holds an inexact array (it could never train).

    def check_jax_operator(op: Any, *inputs: Any, vmap: bool = True) -> None:
    """Assert that ``op`` behaves as a JAX-native pipekit operator.

    Checks, in order:

    1. ``op`` is a pipekit ``Operator`` and an ``eqx.Module``.
    2. Eager ≡ jit: ``op(*inputs)`` equals ``eqx.filter_jit`` of the same
       call, with ``op`` passed as an argument (so its leaves are traced).
    3. Batching (when ``vmap``): stacking every input array along a new
       leading axis and ``jax.vmap``-ing gives the stacked eager outputs.
       Non-array inputs (strings, callables, metadata) are held static.
    4. Leaves visible: every inexact-array field of ``op`` is a leaf of
       ``jax.tree.leaves(op)``, and ``eqx.filter_grad`` of a scalar loss
       returns a gradient for each of them.
    5. Config round trip (unless ``forbid_in_yaml``): ``op.state``
       survives ``json.dumps`` → ``Operator.from_state``; the rebuilt
       operator has the same number of inexact-array leaves (a learnable
       field that came back as a Python float fails here), the same
       array leaves (shape / dtype), and the same outputs. Static fields
       may change container type (a tuple reloads as a list). For an
       operator whose config nests operators (``{"class", "config"}``
       payloads), the children are taken from the live operator and the
       rest is rebuilt from JSON, so local fields are still checked.
    6. No ``static`` field holds an inexact array (it could never train).

    Args:
        op: The operator under test.
        *inputs: Example positional inputs for ``op``.
        vmap: Also check batching over a new leading axis.

    Raises:
        AssertionError: on the first violated property.
    """
    assert isinstance(op, Operator), f"{type(op).__name__} is not a pipekit Operator"
    assert isinstance(op, eqx.Module), f"{type(op).__name__} is not an eqx.Module"

    expected = op(*inputs)
    jitted = eqx.filter_jit(lambda o, *xs: o(*xs))(op, *inputs)
    _assert_tree_allclose(jitted, expected, "eager vs filter_jit")

    if vmap:
        # Batch only the array leaves; static inputs (strings, callables,
        # metadata) are closed over unbatched.
        dynamic, static = eqx.partition(inputs, eqx.is_array)
        if jax.tree.leaves(dynamic):
            batched_dynamic = jax.tree.map(lambda x: jnp.stack([x, x]), dynamic)
            batched = jax.vmap(lambda d: op(*eqx.combine(d, static)))(batched_dynamic)
            _assert_tree_allclose(
                batched,
                jax.tree.map(lambda y: jnp.stack([y, y]), expected),
                "vmap over a leading axis",
            )

    hidden = [
        f.name
        for f in dataclasses.fields(op)
        if f.metadata.get("static")
        and any(eqx.is_inexact_array(x) for x in jax.tree.leaves(getattr(op, f.name)))
    ]
    assert not hidden, (
        f"field(s) {hidden} hold inexact arrays but are static, so they are not "
        "pytree leaves and can never be trained — drop static=True"
    )
    params = [leaf for leaf in jax.tree.leaves(op) if eqx.is_inexact_array(leaf)]
    if params:

        def loss(o: Any) -> Any:
            out = o(*inputs)
            return sum(jnp.sum(jnp.real(y)) for y in jax.tree.leaves(out))

        grads = eqx.filter_grad(loss)(op)
        grad_leaves = [g for g in jax.tree.leaves(grads) if eqx.is_array(g)]
        assert len(grad_leaves) == len(params), (
            f"filter_grad returned {len(grad_leaves)} gradients for "
            f"{len(params)} inexact-array leaves"
        )

    if type(op).forbid_in_yaml:
        return
    state = json.loads(json.dumps(op.state))
    init_fields = {f.name for f in dataclasses.fields(op) if f.init}
    if not set(state["config"]) <= init_fields:
        # A custom get_config whose keys are not constructor fields (one
        # that groups children under a name, say) is checked for its
        # encoding only.
        return
    # Nested children rebuild from their own state records, so the whole
    # operator, local fields and children alike, comes back from JSON.
    rebuilt = Operator.from_state(state)
    rebuilt_params = [
        leaf for leaf in jax.tree.leaves(rebuilt) if eqx.is_inexact_array(leaf)
    ]
    assert len(rebuilt_params) == len(params), (
        f"config round trip turned {len(params) - len(rebuilt_params)} learnable "
        "field(s) into constants — declare them with "
        "eqx.field(converter=jnp.asarray)"
    )
    # Compare the array leaves, not the treedef: static fields are part of
    # the treedef, and JSON legitimately turns a static tuple into a list.
    assert _array_signature(rebuilt) == _array_signature(op), (
        "config round trip changed the operator's array leaves (shape / dtype)"
    )
    _assert_tree_allclose(rebuilt(*inputs), expected, "config round trip")

    pipekit_jax.weights ¶

    Shared weight-blob round trip for pipekit-jax operators.

    WeightsMixin gives an operator serialize_weights / with_weights / from_registry: the array leaves of a pytree are written with equinox.tree_serialise_leaves and read back into a skeleton — an instance with the same pytree structure, whose non-array leaves (activations, dtypes, sizes, static config) cannot be recovered from bytes alone.

    Equinox loads leaves positionally, so a skeleton whose fields are in a different order, or a different class with the same field names — but the same number of leaves and compatible shapes — would silently receive weights it was never trained with. The blob therefore starts with a signature header (tree_signature): the node types of the tree (module.QualName of every pytree node, from the root down, with the structural aux data of non-Equinox nodes such as a pipekit.Graph's wiring) and the key path, shape and dtype of every array leaf. Only array leaves are stored; every non-array value comes from the skeleton. with_weights compares the signature with the skeleton before loading. Node types are read from the treedef, not its repr, and aux data is encoded by _stable, so nothing process-specific (memory addresses) enters the signature.

    Blob layout::

    b"PKJXW1\n" | header length (8 bytes, little endian) | JSON signature
           | equinox.tree_serialise_leaves payload

    Blobs without the magic prefix (written before the header existed) are still accepted and loaded positionally.

    Two hooks pick which pytree is persisted:

    • _weights_tree() — the tree to serialise (default: self).
    • _from_weights_tree(tree) — wrap a deserialised tree back into an operator (default: return tree).

    JaxModelOp persists its wrapped module; JaxOperator persists itself.

    def with_weights(self, blob: bytes) -> Any:
        """Return a new operator with weights loaded from ``blob``.

        ``self`` is the **skeleton** / template — its non-array leaves
        (activations, dtypes, layer sizes) determine the structure into
        which the persisted bytes are loaded. The bytes must come from a
        `serialize_weights` call on an operator with the same pytree
        structure.

        Args:
            blob: Bytes produced by `serialize_weights`.

        Returns:
            A fresh operator carrying the persisted weight values.

        Raises:
            TypeError: if ``blob`` is not bytes.
            ValueError: if the blob's signature (node types, key paths,
                shapes, dtypes) differs from the skeleton's, or — for a legacy
                blob without a signature — if it holds more array leaves
                than the skeleton requests.
            RuntimeError: from newer equinox versions when a
                deserialised leaf's shape/dtype doesn't match the
                skeleton (``eqx.tree_deserialise_leaves``).
        """
        name = type(self).__name__
        if not isinstance(blob, (bytes, bytearray)):
            raise TypeError(
                f"{name}.with_weights(blob): blob must be bytes "
                f"(produced by serialize_weights); got {type(blob).__name__}."
            )
        skeleton = self._weights_tree()
        buf = io.BytesIO(blob)
        if bytes(blob[: len(_MAGIC)]) == _MAGIC:
            buf.seek(len(_MAGIC))
            size = int.from_bytes(buf.read(8), "little")
            saved = json.loads(buf.read(size))
            expected = tree_signature(skeleton)
            if saved["nodes"] != expected["nodes"]:
                raise ValueError(
                    f"{name}.with_weights: the blob's tree structure does not "
                    "match the skeleton: the pytree node types differ (saved "
                    f"root {saved['nodes'][0]!r}, skeleton root "
                    f"{expected['nodes'][0]!r}). Load weights only into the "
                    "class and structure they were saved from."
                )
            saved_leaves, expected_leaves = saved["leaves"], expected["leaves"]
            if saved_leaves != expected_leaves:
                diff = next(
                    (
                        (a, b)
                        for a, b in zip(saved_leaves, expected_leaves, strict=False)
                        if a != b
                    ),
                    (
                        f"{len(saved_leaves)} array leaves",
                        f"{len(expected_leaves)} array leaves",
                    ),
                )
                raise ValueError(
                    f"{name}.with_weights: the blob's tree structure does not "
                    f"match the skeleton (saved {diff[0]!r}, skeleton "
                    f"{diff[1]!r}). Build the skeleton with the same structure, "
                    "field order and shapes as the operator that was serialised."
                )
            arrays = eqx.tree_deserialise_leaves(
                buf, eqx.filter(skeleton, eqx.is_array)
            )
            tree = eqx.combine(arrays, skeleton)
        else:
            # Legacy blob: written with Equinox's default filter.
            tree = eqx.tree_deserialise_leaves(buf, skeleton)
        unread = len(blob) - buf.tell()
        if unread:
            # The skeleton asked for fewer leaves than were saved (e.g. an
            # optional bias that is None in the skeleton): a partial restore
            # would silently drop weights.
            raise ValueError(
                f"{name}.with_weights: {unread} bytes of the blob "
                "were not consumed — the saved tree has more array leaves than "
                "the skeleton. Build the skeleton with the same structure as the "
                "operator that was serialised."
            )
        return self._from_weights_tree(tree)

        """Reload weights stored under ``ref`` into a copy of ``self``.

        The inverse of::

            registry.store(trained_op, weights=trained_op.serialize_weights())

        Args:
            registry: Anything satisfying
                ``pipekit_experiment.ModelRegistry`` (which includes
                ``load_weights(ref) -> bytes | None``).
            ref: Hash or tag identifying the stored model.

            copy of ``self``.

        Raises:

                the raw weight bytes.
            ValueError: if no weights are stored, or they don't match
                ``self``'s structure.

    pipekit_jax.cycle ¶

    ScanCycle and Rollout — jax.lax.scan-based time stepping.

    pipekit_cycle.Cycle is carrier-agnostic and steps in a Python for loop. Under jax.jit that loop unrolls: the traced program, compile time and memory all grow linearly with n_steps, and save_history appends to self.history from inside traced code. That is the right tool for host-side stepping (chunked runs with monitors between chunks) and the wrong one for anything differentiated end to end — 4DVar windows, rollout training.

    • ScanCycle — the JAX specialisation of Cycle: same (carrier, state) -> (carrier, state) contract and the same history convention, one lax.scan regardless of n_steps, and the history is returned by ScanCycle.run, never stored.
    • Rollout — the carrier-only form most PDE use needs: carrier -> trajectory sampled every save_every steps.

    Both accept a pipekit operator or a pipekit_cycle.ForwardModel as the step, are JaxOperator s (so learnable leaves of the step are reachable by eqx.filter_grad), and handle arbitrary pytree carriers — dicts, eqx.Module states, custom carriers — by stacking with jax.tree.map.

                f"got {self.state_axis}."

        """The cycle with its step reading ``state`` directly (not via the carry)."""
        return dataclasses.replace(
            self.cycle, step_op=_ReadOnlyState(self.cycle.step_op, state)
        )

    def _apply(self, carrier: Any, state: Any) -> tuple[Any, Any]:
        # carrier: every leaf has a leading member axis [M, ...]
        if self.state_axis is None:
            cycle = self._read_only_cycle(state)
            out = jax.vmap(lambda c: cycle(c, None)[0])(carrier)
            return out, state
        return jax.vmap(self.cycle)(carrier, state)

        """Like `ScanCycle.run`, per member: histories gain a leading ``M`` axis.

        if self.state_axis is None:
            cycle = self._read_only_cycle(state)
            c, _, hist = jax.vmap(lambda m: cycle.run(m, None))(carrier)
            return c, state, hist
        return jax.vmap(self.cycle.run)(carrier, state)

    def get_config(self) -> dict[str, Any]:
        return {"cycle": nested_config(self.cycle), "state_axis": self.state_axis}

        cᵢ₊₁ = step(cᵢ),   i = 0 … n_steps - 1
        trajectory = (c₀?, c_k, c_2k, …, c_n),   k = save_every

    The trajectory is stacked along a new leading axis with
    ``jax.tree.map``, so any pytree carrier works.

    Attributes:
        step: A pipekit operator ``carrier -> carrier``, or a
            `pipekit_cycle.ForwardModel` (wrapped to call ``step(c, dt)``;
            the wrapper is flagged ``forbid_in_yaml`` so
            `pipekit.check_pickleable` reports it).
        n_steps: Number of steps; must be a multiple of ``save_every``.
        save_every: Record every ``save_every``-th state.
        include_initial: Prepend ``c₀`` to the trajectory.
        checkpoint: Rematerialise each ``save_every`` block on the
            backward pass, so ``grad`` stores carries only at save points
            (which the trajectory keeps anyway) — O(n / save_every +
            save_every) instead of O(n).

    Raises:
        TypeError: If ``step`` is a `StatefulOperator` (use `ScanCycle`),
            or neither an operator nor a `ForwardModel`.
        ValueError: If ``n_steps < 0``, ``save_every < 1``, or
            ``n_steps`` is not a multiple of ``save_every``.
    """

    step: Any = eqx.field(converter=_coerce_carrier_step)
    n_steps: int = eqx.field(static=True, default=1)
    save_every: int = eqx.field(static=True, default=1)
    include_initial: bool = eqx.field(static=True, default=True)
    checkpoint: bool = eqx.field(static=True, default=False)

    def __check_init__(self) -> None:
        if self.n_steps < 0:
            raise ValueError(f"Rollout.n_steps must be >= 0, got {self.n_steps}.")
        if self.save_every < 1:
            raise ValueError(f"Rollout.save_every must be >= 1, got {self.save_every}.")
        if self.n_steps % self.save_every:
            raise ValueError(
                f"Rollout.n_steps ({self.n_steps}) must be a multiple of "
                f"save_every ({self.save_every})."
            )

    def _apply(self, carrier: Any) -> Any:
        def inner(c: Any, _: Any) -> tuple[Any, None]:
            return self.step(c), None

        def outer(c: Any, _: Any) -> tuple[Any, Any]:
            c, _ = jax.lax.scan(inner, c, None, length=self.save_every)
            return c, c

        if self.checkpoint:  # keep carries only at save points
            outer = jax.checkpoint(outer)

        n_saves = self.n_steps // self.save_every
        if n_saves:
            _, traj = jax.lax.scan(outer, carrier, None, length=n_saves)
        else:
            traj = jax.tree.map(_empty_history, carrier)
        if not self.include_initial:
            return traj
        return jax.tree.map(
            lambda c0, t: jnp.concatenate([jnp.asarray(c0)[None], t]), carrier, traj
        )

    def get_config(self) -> dict[str, Any]:
        return {
            "step": nested_config(self.step),
            "n_steps": self.n_steps,
            "save_every": self.save_every,
            "include_initial": self.include_initial,
            "checkpoint": self.checkpoint,
        }

    class ScanCycle(StatefulOperator, JaxOperator):
    """Apply ``step_op`` for ``n_steps`` inside one ``jax.lax.scan``.

    The jit-native counterpart of `pipekit_cycle.Cycle`.

    .. code-block:: text

        (cᵢ₊₁, sᵢ₊₁) = step_op(cᵢ, sᵢ),   i = 0 … n_steps - 1

    Calling the operator returns ``(c_n, s_n)`` exactly like ``Cycle``.
    `run` additionally returns the history, recorded with ``Cycle``'s
    convention — after step ``i + 1`` for every ``i`` with
    ``i % history_stride == 0`` — so there are ``⌈n_steps / stride⌉``
    entries.

    Attributes:
        step_op: A `StatefulOperator` ``(carrier, state) -> (carrier,
            state)``, or a `pipekit_cycle.ForwardModel` (wrapped so the
            state passes through unchanged).
        n_steps: Number of steps (``>= 0``; ``0`` is a no-op).
        history_stride: Record every ``stride``-th step in `run`.
        checkpoint: Rematerialise on the backward pass. The forward pass
            keeps the carry only at chunk boundaries — every ``⌈√n⌉``
            steps when called, every ``history_stride`` steps in `run` —
            and reverse mode recomputes the steps inside a chunk. Memory
            for ``grad`` drops from O(n) carries to O(√n) (or
            O(n / stride + stride)) at the cost of one extra forward pass.
        truncate: If set to ``k``, gradients flow through the carry of
            the trailing ``k`` steps only (the carry leaving step ``i``
            is ``stop_gradient``-ed when ``i < n_steps - k``), matching
            `pipekit_jax.truncated_scan`: history entries recorded by
            `run` keep the gradient of their own step, as scan outputs
            do. Forward values are unchanged.

    Raises:
        TypeError: If ``step_op`` is neither a `StatefulOperator` nor a
            `ForwardModel`.
        ValueError: If ``n_steps < 0``, ``history_stride < 1`` or
            ``truncate < 1``.

    Example:
        >>> cycle = ScanCycle(step_op=model_op, n_steps=1000, history_stride=100)
        >>> carrier, state = eqx.filter_jit(cycle)(c0, s0)
        >>> carrier, state, (carriers, states) = eqx.filter_jit(cycle.run)(c0, s0)
    """

    step_op: Any = eqx.field(converter=_coerce_step)
    n_steps: int = eqx.field(static=True, default=1)
    history_stride: int = eqx.field(static=True, default=1)
    checkpoint: bool = eqx.field(static=True, default=False)
    truncate: int | None = eqx.field(static=True, default=None)

    def __check_init__(self) -> None:
        if self.n_steps < 0:
            raise ValueError(f"ScanCycle.n_steps must be >= 0, got {self.n_steps}.")
        if self.history_stride < 1:
            raise ValueError(
                f"ScanCycle.history_stride must be >= 1, got {self.history_stride}."
            )
        if self.truncate is not None and self.truncate < 1:
            raise ValueError(f"ScanCycle.truncate must be >= 1, got {self.truncate}.")

    def _cut(self, carry: tuple[Any, Any], i: Any) -> tuple[Any, Any]:
        """Stop gradients through the carry leaving step ``i`` (``truncate``)."""
        if self.truncate is None:
            return carry
        cut = i < self.n_steps - self.truncate
        return jax.tree.map(
            lambda x: jnp.where(cut, jax.lax.stop_gradient(x), x), carry
        )

    def _step(self, carry: tuple[Any, Any], i: Any) -> tuple[Any, Any]:
        return self._cut(self.step_op(*carry), i)

    def _apply(self, carrier: Any, state: Any) -> tuple[Any, Any]:
        chunk = max(1, math.isqrt(self.n_steps)) if self.checkpoint else None
        return _scan_steps(self._step, (carrier, state), 0, self.n_steps, chunk)

    def run(self, carrier: Any, state: Any) -> tuple[Any, Any, Any]:
        """Run the cycle and return ``(carrier, state, (carriers, states))``.

        ``carriers`` / ``states`` stack the recorded entries along a new
        leading axis of length ``⌈n_steps / history_stride⌉`` (zero when
        ``n_steps == 0``).
        """
        step, k, n = self._step, self.history_stride, self.n_steps
        carry = (carrier, state)
        if n == 0:
            return carrier, state, jax.tree.map(_empty_history, carry)

        def body(c: Any, i: Any) -> tuple[Any, None]:
            return step(c, i), None

        def group(c: Any, j: Any) -> tuple[Any, Any]:
            # one recorded step (global index j·k), then k - 1 unrecorded ones.
            # Record *before* the truncation cut, like truncated_scan's
            # outputs: an entry keeps the gradient of its own step even
            # when the carry it passes on is cut.
            recorded = self.step_op(*c)
            c = self._cut(recorded, j * k)
            if k > 1:
                c, _ = jax.lax.scan(body, c, j * k + jnp.arange(1, k))
            return c, recorded

        if self.checkpoint:  # keep carries only at group boundaries
            group = jax.checkpoint(group)

        full, rem = divmod(n, k)
        history = []
        if full:
            carry, hist = jax.lax.scan(group, carry, jnp.arange(full))
            history.append(hist)
        if rem:
            recorded = self.step_op(*carry)
            history.append(_stack([recorded]))
            carry = self._cut(recorded, full * k)
            carry = _scan_steps(step, carry, full * k + 1, rem - 1)
        hist = (
            history[0]
            if len(history) == 1
            else jax.tree.map(lambda *xs: jnp.concatenate(xs), *history)
        )
        return carry[0], carry[1], hist

    def get_config(self) -> dict[str, Any]:
        return {
            "step_op": nested_config(self.step_op),
            "n_steps": self.n_steps,
            "history_stride": self.history_stride,
            "checkpoint": self.checkpoint,
            "truncate": self.truncate,
        }

    JaxModelOp¶

    pipekit_jax.model_op ¶

    JaxModelOp — pipekit.Operator wrapper around an eqx.Module.

    Closes the v0.1 reproducibility caveat documented in pipekit-train/docs/design/boundaries.md §13.1: the in-package EquinoxModelOp stand-in shipped with v0.1 couldn't round-trip trained weights through a ModelRegistry from JSON config alone, because an eqx.Module is a JAX PyTree of arrays whose values aren't recoverable from a class name.

    JaxModelOp adds two methods on top of the same wrapper surface:

    • serialize_weights() -> bytes — a leaf-signature header plus eqx.tree_serialise_leaves of the wrapped module's array leaves. Suitable for the registry's weights blob.
    • with_weights(blob: bytes) -> JaxModelOp — load the bytes back into the module's array leaves, returning a new JaxModelOp whose module is structurally identical to self.module but with the persisted weight values. self is the skeleton / template.

    The skeleton-from-template requirement is honest: an eqx.Module's non-array leaves (activation functions, dtypes, hidden-size ints) are Python objects not reproducible from JSON alone. The user always needs to build a fresh module of the same shape before calling with_weights. from_registry packages the "reload weights from a stored hash into self" pattern into one call.

    def truncated_scan[Carry, X, Y](
    f: Callable[[Carry, X], tuple[Carry, Y]],
    init: Carry,
    xs: X,
    *,
    k: int = 1,
) -> tuple[Carry, Y]:
    """``jax.lax.scan`` with gradients truncated to the trailing ``k`` steps.

    The carry leaving every step before ``T - k`` is wrapped in
    ``stop_gradient``, so reverse-mode differentiation sees only the
    last ``k`` transitions *through the carry*. Each step's own output
    ``y_t`` still receives gradients with respect to that step's
    inputs — only the flow through history is cut, which is exactly
    the ROAD-EnKF / truncated-BPTT training regime. ``k >= T`` is the
    identity transformation (a plain scan).

    Memory for the backward pass is O(k) in the rollout length instead
    of O(T), and for chaotic step functions the truncation acts as
    gradient regularisation (the exact adjoint norm grows like
    ``exp(lambda_max * T)``).

    Args:
        f: Scan body ``(carry, x) -> (carry, y)``.
        init: Initial carry.
        xs: Stacked per-step inputs with leading axis ``T``.
        k: Number of trailing steps that propagate gradients
            through the carry. Must be at least 1.

    Returns:
        ``(final_carry, ys)`` exactly as ``jax.lax.scan`` would —
        the forward values are identical; only gradients differ.

    Raises:
        ValueError: if ``k < 1`` or ``xs`` has no leading axis.
    """
    if k < 1:
        raise ValueError(f"truncated_scan needs k >= 1; got k={k}.")
    leaves = jax.tree.leaves(xs)
    if not leaves:
        raise ValueError("truncated_scan needs at least one stacked input in xs.")
    length = leaves[0].shape[0]
    cutoff = length - k

    def body(carry: Carry, indexed: tuple[Any, X]) -> tuple[Carry, Y]:
        i, x = indexed
        new_carry, y = f(carry, x)
        # jnp.where keeps the graph differentiable in the trailing
        # window and routes earlier steps through stop_gradient.
        cut = i < cutoff
        new_carry = jax.tree.map(
            lambda c: jnp.where(cut, jax.lax.stop_gradient(c), c), new_carry
        )
        return new_carry, y

    return jax.lax.scan(body, init, (jnp.arange(length), xs))

    class DiffraxForwardModel(eqx.Module):
    """Advance a state with ``diffrax.diffeqsolve``.

    ODE by default; supply ``diffusion`` (and ``sde_key``) for an SDE,
    in which case the Brownian path is a ``VirtualBrownianTree`` over
    each integration span. The adjoint spec selects how reverse-mode
    gradients flow through the solve (default: treeverse
    checkpointing, the robust choice — see
    ``pipekit_cycle.adjoints`` for the menu and the warning on
    ``BacksolveAdjoint``).

    pipekit cycles call ``step(state, dt)`` with no absolute time, so
    integration always runs over ``[0, dt]`` (autonomous dynamics);
    ``as_dynamics()`` exposes the explicit ``(state, t0, t1)`` form
    used by algorithm libraries (e.g. filterax ``AbstractDynamics``).

    Attributes:
        vector_field: Drift ``f(t, y, args) -> dy/dt`` in diffrax
            convention.
        solver: Any diffrax solver (``Tsit5()`` for non-stiff ODEs,
            ``Kvaerno5()`` for stiff, ``Euler()``/``Heun()`` for
            SDEs, ...).
        dt0: Initial/fixed integrator step.
        dt: Default window length advertised to pipekit cycles.
        adjoint: Adjoint spec (or a raw ``diffrax.AbstractAdjoint``).
        stepsize_controller: diffrax step-size controller; defaults to
            constant steps.
        diffusion: Optional ``g(t, y, args)`` turning the solve into
            an SDE ``dy = f dt + g dW``. Per diffrax >= 0.7 semantics
            the return value must be a *linear map* from the Brownian
            increment into state space — e.g.
            ``lineax.DiagonalLinearOperator(sigma)`` for diagonal
            noise, or a ``(N_x, N_w)`` matrix.
        brownian_shape: Shape of the Brownian increment (SDE only).
            ``None`` derives it from the state — correct for diagonal
            noise. For non-square noise (a diffusion returning an
            ``(N_x, N_w)`` linear map with ``N_w != N_x``) pass
            ``(N_w,)`` explicitly.
        sde_key: PRNG key for the Brownian path (SDE only). The key is
            fixed at construction; refresh it per cycle through your
            DA state (e.g. ``DAState.extras["rng_key"]``) by rebuilding
            with ``dataclasses.replace`` if independent paths per
            window are required.
        max_steps: Bound on integrator steps per solve.
    """

    vector_field: Callable[[Any, Any, Any], Any]
    solver: diffrax.AbstractSolver = diffrax.Tsit5()
    dt0: float = 0.01
    dt: float = 1.0
    adjoint: Any = eqx.field(static=True, default_factory=RecursiveCheckpointAdjoint)
    stepsize_controller: diffrax.AbstractStepSizeController = diffrax.ConstantStepSize()
    diffusion: Callable[[Any, Any, Any], Any] | None = None
    sde_key: jax.Array | None = None
    brownian_shape: tuple[int, ...] | None = eqx.field(static=True, default=None)
    max_steps: int = eqx.field(static=True, default=4096)

    def __check_init__(self) -> None:
        if self.diffusion is not None and self.sde_key is None:
            raise ValueError(
                "SDE dynamics (diffusion is not None) need an sde_key for the "
                "VirtualBrownianTree."
            )

    def _terms(self, t0: Any, t1: Any, state: Any) -> Any:
        drift = diffrax.ODETerm(self.vector_field)
        if self.diffusion is None:
            return drift
        bm_shape = (
            self.brownian_shape if self.brownian_shape is not None else jnp.shape(state)
        )
        brownian = diffrax.VirtualBrownianTree(
            t0,
            t1,
            tol=self.dt0 / 2,
            shape=jax.ShapeDtypeStruct(bm_shape, jnp.result_type(state)),
            key=self.sde_key,
        )
        return diffrax.MultiTerm(drift, diffrax.ControlTerm(self.diffusion, brownian))

    def _solve(self, state: Any, t0: Any, t1: Any) -> Any:
        sol = diffrax.diffeqsolve(
            self._terms(t0, t1, state),
            self.solver,
            t0=t0,
            t1=t1,
            dt0=self.dt0,
            y0=state,
            stepsize_controller=self.stepsize_controller,
            adjoint=to_diffrax_adjoint(self.adjoint),
            max_steps=self.max_steps,
            saveat=diffrax.SaveAt(t1=True),
        )
        return jax.tree.map(lambda y: y[-1], sol.ys)

    def step(self, state: Any, dt: Any) -> Any:
        """Advance ``state`` by ``dt`` (autonomous: integrates ``[0, dt]``)."""
        return self._solve(state, jnp.zeros_like(jnp.asarray(dt)), dt)

    @property
    def state_signature(self) -> None:
        """No shape contract advertised; pipekit treats ``None`` as opt-out."""
        return None

    def with_adjoint(self, spec: Any) -> DiffraxForwardModel:
        """Return a copy configured with another adjoint spec."""
        return dataclasses.replace(self, adjoint=spec)

    def as_dynamics(self) -> Callable[[Any, Any, Any], Any]:
        """Return the ``(state, t0, t1) -> state`` callable form.

        Plugs directly into APIs that take explicit integration spans,
        e.g. filterax ``AbstractDynamics`` slots or vardax 4D-Var
        ``forward`` arguments.
        """
        return self._solve
